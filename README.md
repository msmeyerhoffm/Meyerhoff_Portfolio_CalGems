# CalGEM Training Analyst Portfolio

This repository hosts a focused interview portfolio with three work samples:

1. WellSTAR Competency Assessment
2. Training Operations System
3. Branding and Accessibility Update

## GitHub Pages

Enable GitHub Pages from the `main` branch and `/root` folder. The site homepage is `index.html`.

## File structure

```text
index.html
styles.css
wellstar/
  story.html
  story_content/
  html5/
files/
  WellSTAR_Competency_Dashboard_Polished.xlsx
  CalGEM_Training_Operations_Workbook_Final.xlsx
  CalGEM_Branding_Accessibility_Update.pdf
```

Publish the Storyline course for Web and copy the complete published output into the `wellstar` folder without changing its internal structure.

The portfolio samples are independent work developed from publicly available materials and are not official California Department of Conservation or CalGEM products.
