# Portfolio Images

Upload screenshots to this folder using these exact filenames so the website displays them automatically:

- `wellstar-assessment.png` — Storyline WellSTAR assessment screenshot
- `training-operations.png` — Training Operations workbook or calendar screenshot
- `branding-before.png` — original public-facing material
- `branding-after.png` — revised branding/accessibility version

The homepage already references these paths. Once the files are uploaded, the placeholders on the site will be replaced by the screenshots automatically.
